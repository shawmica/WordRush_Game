# WordRush_Game

🚀 Just launched Word Rush Arena – a fast-paced vocabulary game built with React!
🎮 Challenge your mind with Classic Mode – form as many words as you can in 60 seconds from randomized letters!
🔤 Designed to boost language skills and quick thinking under pressure.

🛠️ Built using: React, CSS, JavaScript
🎯 Features: Real-time scoring, countdown timer, dynamic word validation

More exciting game modes on the way – including Unlimited Practice mode to build words freely without the pressure of a timer!
